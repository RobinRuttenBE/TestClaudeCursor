## ACTIEPUNTEN (data/tooling, geen contentadvies)

1. **Facebook Page token vernieuwen.** De Instagram MCP kan geen Facebook calls meer doen ("session is invalid because the user logged out"). Metricool vangt dit nu op, maar levert geen page reach en geen reel reach. Volg de procedure in de memory `reference_facebook_token.md`: genereer een User Access Token via Graph API Explorer met `pages_read_engagement`, `pages_read_user_content`, `read_insights` en `pages_show_list`.
2. **Instagram profielbezoeken en link clicks blijven leeg.** De MCP tool `instagram_get_account_insights` stuurt geen `metric_type=total_value` mee, wat de Graph API vereist voor `profile_views`, `website_clicks` en `views`. In Metricool zijn diezelfde velden als deprecated gemarkeerd. Zonder aanpassing van de MCP tool blijven deze twee KPI's structureel onmeetbaar.
3. **Stories zijn nu wel meetbaar.** De Instagram Graph API geeft alleen actieve stories terug (deze week: nul, want gemeten op maandagochtend). Metricool heeft de historie wel. Vanaf nu komen stories count en stories impressions uit Metricool. Voor week 27 tot en met 31 is dit alsnog op te halen als je de gaten in de tracker wilt vullen.
4. **Week 28 en 29 ontbreken nog steeds** in de Google Sheet. Metricool heeft deze data wel, dus dit gat is te dichten.
